# HyperFrames 视频素材规范

## 目录结构

```
~/.openclaw/workspace/video-projects/
├── [project-name]/
│   ├── index.html          # 主视频文件
│   ├── compositions/      # 子场景组件
│   ├── assets/            # 静态资源
│   │   ├── images/        # 图片素材
│   │   ├── audio/        # 音频文件
│   │   └── fonts/        # 字体文件
│   ├── output/            # 渲染输出
│   │   └── [timestamp].mp4
│   └── design.md         # 设计规范
├── temp/                 # 临时文件（自动清理）
└── archive/             # 归档目录
```

## 命名规范

### 项目命名
- 格式: `YYYY-MM-DD_topic-slug`
- 示例: `2026-05-09_time-management`

### 输出文件
- 格式: `{project-name}_{resolution}_{timestamp}.mp4`
- 示例: `time-management_1920x1080_20260509.mp4`

## 视频规格

### 分辨率
| 类型 | 尺寸 | 用途 |
|------|------|------|
| 横屏 | 1920×1080 | 通用 |
| 竖屏 | 1080×1920 | 抖音/视频号 |
| 方形 | 1080×1080 | Instagram |

### 时长
- 最优: 30-60秒
- 最大: 180秒
- 最少: 5秒

### 帧率
- 标准: 30fps
- 流畅: 60fps

## 样式规范

### 背景色
- 深色主题: #0a1628 → #1a2840（渐变）
- 浅色主题: #ffffff → #f5f5f5（渐变）

### 配色方案
| 用途 | 色值 |
|------|------|
| 主色 | #3b82f6 |
| 强调色 | #f59e0b |
| 文字色 | #ffffff |
| 次要文字 | #94a3b8 |

### 字体
- 标题: Inter Bold
- 正文: Inter Regular
- 代码: JetBrains Mono

## 动画规范

### 时长
- 进入动画: 0.3-0.6秒
- 退出动画: 0.3-0.5秒
- 过渡动画: 0.2-0.4秒

### 缓动函数
- ease-out: 进场
- ease-in: 退场
- ease-in-out: 过渡

## 素材要求

### 图片
- 格式: PNG/WebP
- 最大尺寸: 1920×1080
- 最大文件: 2MB

### 音频
- 格式: MP3/WAV
- 时长: 与视频一致
- 采样率: 44.1kHz

## 元素清单

### 必选
- [ ] 标题文字
- [ ] 背景
- [ ] 主体内容
- [ ] 退出动画

### 可选
- [ ] 旁白配音
- [ ] 背景音乐
- [ ] 字幕
- [ ] 转场效果
- [ ] 片头/片尾
- [ ] 品牌标识

## 场景类型

### 1. 标题卡 (Title Card)
```
- 大标题（居中）
- 副标题（可选）
- 时长: 2-3秒
```

### 2. 内容卡 (Content Card)
```
- 标题
- 要点列表
- 视觉元素
- 时长: 5-15秒
```

### 3. 数据卡 (Data Card)
```
- 图表
- 数值
- 说明文字
- 时长: 5-10秒
```

### 4. 对比卡 (Comparison Card)
```
- 左侧内容
- 右侧内容
- 分隔线
- 时长: 8-15秒
```

### 5. 结尾卡 (End Card)
```
- CTA 文字
- 二维码（可选）
- 关注引导
- 时长: 3-5秒
```

## 保存策略

- **草稿**: 保留到渲染完成
- **成片**: 保留7天
- **源文件**: 保留30天（可恢复）
- **临时文件**: 渲染后立即删除

## 快速命令

```bash
# 预览
npx hyperframes preview

# 渲染
npx hyperframes render

# 清理临时文件
npx hyperframes clean

# 查看输出
open output/
```
