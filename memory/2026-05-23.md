## Fixed: Gateway Runtime 断时连

**Root causes:**
1. `openclaw.json` 残留 `"cron": {}` 空对象 — cron 任务已迁移到独立文件 `cron/jobs.json`，但 `cron: {}` 未清理，导致配置校验失败
2. Gateway 内置的 stale-PID 清理机制会杀掉 systemd 跟踪的上一个进程，systemd 检测到主进程死亡后立即重启 → 新实例杀掉旧实例 → 无限循环

**Fixes applied:**
1. `openclaw.json`: 删除了 `cron` 字段
2. `~/.config/systemd/user/openclaw-gateway.service.d/stale-cleanup.conf`: 创建 systemd override，在启动前先 pkill 所有旧 gateway 进程

**Current state:** Gateway (PID 15702) 由 systemd 管理，已稳定运行 2+ 分钟，NRestarts=0，port 18789 正常响应 HTTP 200。
