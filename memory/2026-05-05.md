## CLI-Anything 技能分享

### 核心价值
- 让所有软件都能被 AI 代理驱动
- 通过 CLI 接口连接 AI 与专业软件
- 7 步全自动流水线，从源码到可发布 CLI

### 已支持的软件生态
- 🎨 创意设计：GIMP, Blender, Inkscape, Krita
- 🎬 音视频处理：Audacity, Shotcut, OBS Studio
- 📊 生产力工具：LibreOffice, Draw.io, Notion
- 🤖 AI 内容生成：Stable Diffusion WebUI, ComfyUI

### 用户的实践经验

- 最优方案：先图生模，然后再扔给 Blender 细化

### Hermes Agent 必装五款神器

#### 1️⃣ GStack - 虚拟软件工程团队
- **核心理念**：给 AI 装备十种不同角色的"专家思维模式"
- **核心功能**：
  - /plan-ceo-review → 创始人视角，重新审视需求
  - /plan-eng-review → 工程经理视角，严锁架构和实现边界
  - /review → 资深工程师视角，挑剔地找生产级 Bug
  - /ship → 发布工程师，一键测试→PR→发布全流程
  - /browse → QA 工程师，让 AI 直接看真实浏览器验证 UI
  - /qa → QA 负责人，带健康评分的自动化测试报告
  - /retro → 工程回顾，数据驱动分析团队贡献趋势
  - /document-release → 技术文档，确保发布说明与代码同步
- **亮点**：完全免费 MIT 协议、持续活跃更新、全流程覆盖
- **适合人群**：工程团队、技术负责人、重视代码质量的开发者

#### 2️⃣ GBrain - AI 的第二大脑
- **核心理念**：把 Markdown 笔记变成 AI 可搜索、可推理、持续增长的"记忆系统"
- **核心功能**：
  - Compiled Truth：每页顶部是当前最佳理解，证据变化时自动重写
  - Timeline：底部是永不篡改的时间线，时间戳 + 来源 + 原始引用
  - Dream Cycle：夜间自动运行，丰富实体信息、修复引用断裂
  - 混合搜索：关键字 + 向量 + RRF 倒数排名融合搜索
  - 自动交叉引用：页面间自动建立 backlink，关系图谱自动维护
- **存储规模参考**：17,888 页知识库（人物档案 10,000+ 页、公司页面 3,000+ 个等）
- **亮点**：Markdown + Git 存储、零配置起步、10万页也能毫秒查询
- **适合人群**：知识工作者、创始人、投资人

#### 3️⃣ Hermes WebUI - 浏览器管理界面
- **核心理念**：给 Hermes Agent 配一个浏览器里的"控制台"
- **核心功能**：
  - 多会话统一管理：按平台分组、实时流式渲染、全局搜索
  - 8 大平台渠道一键配置：IM/办公软件配置自动写入 config.yaml
  - 精细化成本监控：按模型/会话统计 Token 消耗、30天趋势图表
  - 可视化 Cron 任务：表单配置定时任务、手动触发 + 执行日志查看
  - Web 终端：内置 node-pty 终端
- **亮点**：零门槛、响应式设计、自动检测并启动 Hermes Gateway
- **适合人群**：运营团队、管理者、技术负责人

#### 4️⃣ Awesome Hermes Agent - 社区资源导航
- **核心理念**：Hermes Agent 生态的资源导航
- **收录内容**：
  - 内置 Skills：77 个官方内置
  - 推荐 Skills：50 个官方推荐
  - 社区 Skills：500+ 社区贡献
  - 插件、部署工具、集成方案
- **亮点**：分类清晰、社区维护、有安全扫描标注
- **适合人群**：所有 Hermes Agent 用户

#### 5️⃣ Self-Evolution - 自我进化引擎
- **核心理念**：AI 在任务上反复失败时，自己跑一轮进化算法
- **核心机制**：
  - AI 在任务上反复失败
  - 启动进化算法
  - 生成技能描述/工具参数/提示词变体
  - 评估筛选（无需 GPU）
  - 收敛到更优方案
  - 下次任务表现更好
- **亮点**：$2–10 低成本、全自动闭环、持续自我改进
- **适合人群**：需要 AI 长时间自主运作、持续自我改进的高级用户

### 五款工具总结
| 项目 | 解决的问题 | 核心用户 | 门槛 |
|------|-----------|---------|------|
| GStack | AI 输出质量不稳定、缺专家思维 | 工程团队 | 需用 Claude Code |
| GBrain | AI 每次都当你是陌生人 | 知识工作者 | 需配置 Postgres |
| Hermes WebUI | 命令行门槛高、不够可视化 | 运营/管理岗 | 零门槛 |
| Awesome Hermes | 不知道有哪些能力可用 | 所有用户 | 零门槛 |
| Self-Evolution | AI 无法自主进步 | 高级用户 | 有一定配置要求 |

### 核心痛点覆盖
- 🧠 输出质量 ← GStack 专家思维模式
- 📚 记忆积累 ← GBrain 第二大脑
- 🖥️ 可视管理 ← Hermes WebUI 控制台
- 🗺️ 生态发现 ← Awesome Hermes Agent
- 🚀 自主进化 ← Self-Evolution
